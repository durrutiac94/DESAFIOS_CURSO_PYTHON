DESAFIO INTRODUCCION A DJANGO

Pasos para completar el desafío

  1. Crear directorio del proyecto
  2. Copiar el archivo requirements.txt en la carpeta
  3. Crear el ambiente virtual con py -m venv ambiente_virtual
  4. Activar el ambiente virtual con \Scripts\activate
  6. Instalar las dependencias con pip install -r requirements.txt
  7. Verificar que se encuentren las versiones correctas con pip-list
  8. Volver al directorio anterior con cd..
  9. Iniciar el proyecto con django-admin startproject desafio1
  10. Crear el archivo views.py
  11. Importar render
  12. Crear la función home, about y contact
  13. Crear la carpeta templates
  14. Crear los archivos home.html, about.html y contact.html
  15. Modificar los path en el archivo urls.py para redireccionar a los templates creados
  16. Modificar el archivo settings.py y modificar 'DIRS': [BASE_DIR / 'templates']
  17. Iniciar el servidor con py manage.py runserver
